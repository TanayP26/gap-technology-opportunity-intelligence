# Visual direction

GAP should feel like a research instrument, not an AI landing-page template.

## Character

- Dense enough to look useful, never cramped.
- Quiet surfaces, strong information hierarchy.
- Data carries the visual interest.
- Animations explain state changes; they are not decoration.

Reference mood: scientific software + Linear-like restraint + market terminal density. Do not clone any product.

## Avoid

- purple/blue gradient backgrounds
- glassmorphism
- giant rounded cards everywhere
- random sparkles or robot icons
- neon glow around every chart
- `AI INSIGHT` badges
- fake testimonials or fake company logos
- excessive pill-shaped controls
- lorem ipsum
- generated-looking marketing copy
- charts with unexplained scores

## Layout

Desktop max width: 1440px.

Left rail: 216px when needed.

Content grid: 12 columns.

Use large whitespace around page titles, tighter spacing inside data sections.

## Radius

- controls: 6px
- data panels: 8px
- modals: 10px

Do not use 20-32px SaaS-card radii.

## Typography

Use one serious sans-serif family. Inter is acceptable if no custom typography work is available. Pair it with a mono font only for IDs, source labels, timestamps, and numeric diagnostics.

Page title: 28-32px.
Section title: 16-18px.
Body: 14px.
Dense metadata: 12px.

## Copy style

Prefer:

`5 sources · 162 evidence items · updated 18:42 IST`

over:

`✨ AI-powered insights gathered from across the web`

Prefer:

`Research activity exceeds visible commercial presence.`

not:

`Massive untapped opportunity detected!`

## Core visual: landscape

X axis: visible market presence.
Y axis: technical momentum.
Bubble size: demand momentum.
Bubble opacity/stroke treatment: confidence.

Always include an accessible table below or beside the chart.

## Signal detail

Show the five source signals independently before showing `gap_score`.

The score should be secondary and accompanied by a short formula explanation. The product's visual language should reward inspection rather than gamification.
